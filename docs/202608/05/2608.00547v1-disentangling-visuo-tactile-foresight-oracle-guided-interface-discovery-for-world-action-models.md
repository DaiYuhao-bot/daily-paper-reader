## 摘要
接触丰富的操作仍然具有挑战性，因为成功的控制依赖于通常仅从视觉中难以观察到的物理交互线索。最近触觉世界行动模型联合建模未来的视觉观测和触觉信号以指导动作生成，但如何为行动专家有效使用这些未来信息构建合适结构仍未得到充分探索。直接使用学习到的世界行动模型研究这一问题很困难，因为端到端行为会纠缠物理上无效的视觉未来、不可靠的预测、不准确或跨模态不一致的触觉预测，以及难以理解的未来到动作接口。为了使该接口可独立研究，我们引入了Oracle视觉-触觉预见（OVTF），一个受控框架，提供来自模拟中验证成功的轨迹的配对RGB和触觉未来。通过固定未来提供者，OVTF隔离了接口并提出一个更清晰的问题：如果未来是成功的且物理上可执行的，什么表示能让行动专家吸收其益处？在OVTF内，我们提出非对称相位局部未来记忆（AFM），其中视觉记忆读取未来视觉，每个触觉记忆联合关注自身的触觉流和相位对齐的未来视觉，并阻止跨触觉访问。我们将AFM与模态隔离未来记忆（IFM）进行比较，后者移除视觉到触觉的访问并独立处理每个未来模态。在UniVTAC模拟基准的七个任务中，AFM平均成功率达到32.0%，而IFM为23.7%，UniVTAC-ACT为14.9%。这一受控比较表明，选择性相位对齐的视觉-触觉路由提供了比完全模态隔离更具可操作性的未来到动作桥梁。

## Abstract
Contact-rich manipulation remains challenging because successful control depends on physical interaction cues that are often weakly observable from vision alone. Recent tactile world action models jointly model future visual observations and tactile signals to guide action generation, but how such futures should be structured for effective use by the action expert remains underexplored. Directly studying this question with learned world action models is difficult because end-to-end behavior entangles physically invalid visual futures, unreliable predictions, inaccurate or cross-modally inconsistent tactile forecasts, and an unreadable future-to-action interface. To make this interface independently studyable, we introduce Oracle Visuo-Tactile Foresight (OVTF), a controlled framework that supplies paired RGB and tactile futures from successful trajectories verified in simulation. By fixing the future provider, OVTF isolates the interface and asks a cleaner question: if the future is successful and physically executable, what representation allows the action expert to absorb its benefit? Within OVTF, we propose Asymmetric Phase-Local Future Memory (AFM), in which visual memory reads future vision, each tactile memory jointly attends to its own tactile stream and phase-aligned future vision, and cross-tactile access is blocked. We compare AFM with Modality-Isolated Future Memory (IFM), which removes visual-to-tactile access and processes each future modality independently. Across seven tasks on the UniVTAC simulation benchmark, AFM achieves 32.0% average success, compared with 23.7% for IFM and 14.9% for UniVTAC-ACT. This controlled comparison shows that selective phase-aligned visual-tactile routing provides a more actionable future-to-action bridge than complete modality isolation.

- **研究壁垒**：直接使用端到端学习的世界行动模型研究该问题非常困难，因为最终任务得分中混杂了四个相互纠缠的因素：

  4. 即使未来是正确的，编码形式也可能无法被动作分支高效读取。
- **整体含义**：论文认为，视觉-触觉预见的有效性不仅取决于未来是否预测得准，还取决于是否通过一个动作专家能有效消费的接口来传递。因此，需要**将未来提供方与未来→动作接口解耦**，独立研究接口本身的质量。

## 2. 论文提出的方法论：核心思想、关键技术细节与公式

### 2.1 Oracle Visuo-Tactile Foresight（OVTF）框架

- **核心思想**：通过**固定未来提供者**，使接口可以被独立研究。OVTF 不从学习得到的预测器获取未来，而是从成功演示轨迹中抽取配对、按时间排序、与当前初始化匹配且经模拟验证成功的 RGB 和触觉未来片段。
- **关键设计**：
  - 未来来源是“特权诊断源”，**不提供**未来动作、未来 qpos、对象位姿、模拟器状态、成功标签等特权元数据，仅提供参考轨迹的视觉图像和左右触觉 RGB。
  - 未来采样采用**相位（phase）**概念：对参考索引 τref，采样帧的归一化剩余水平相位为：

    φi = (τi − τref) / max(1, T − 1 − τref)，φi ∈ [0, 1]

  - 从每条轨迹中至多均匀采样 N = 100 帧，经可训练的 ResNet-18 编码后得到三个序列 H, L, R ∈ R^N×512。
  - 每个未来序列经过**门控局部时间残差**（gated local temporal residual）模块：

    X′m = Xm + tanh(gm) · ConvDW(LN(Xm))

    其中 ConvDW 为深度可分离卷积（kernel size 5, padding 2, 512 groups），三个门 gm 初始化为零，保证初始化时不影响原策略。

### 2.2 Asymmetric Phase-Local Future Memory（AFM）

- **结构**：AFM 包含 12 个可学习的 512 维槽位——4 个视觉槽、4 个左触觉槽、4 个右触觉槽。每个模态使用固定相位锚点 C = {0.125, 0.375, 0.625, 0.875}。
- **注意力机制**：对每个允许的源序列，执行一次联合多头注意力：

    score_{hk,i} = (q_hk)^T k_hi / √64 − (φi − ck)² / (2 × 0.18²)

    即内容注意力之外叠加**高斯相位先验**（软约束，非硬窗口）。
- **关键路由模式**（不对称融合）：

    H ← H, L ← (L, H), R ← (R, H)

  - 视觉记忆读取未来视觉；
  - 每个触觉记忆**联合关注自身触觉流 + 相位对齐的未来视觉**；
  - **阻断 L ↔ R 跨触觉访问**（左触觉与右触觉之间不互相读取）。

- **对照方法 IFM（Modality-Isolated Future Memory）**：路由模式简化为 H ← H, L ← L, R ← R，即完全模态隔离，移除视觉→触觉读取边。其余设置（未来提供者、相位锚点、记忆预算、训练数据、优化配置）完全相同，保证对比的纯粹性。

### 2.3 ACT 策略集成

- 当前视觉/触觉观测由冻结的 UniVTAC-ACT* 编码器处理，qpos 经冻结的状态投影得到当前空间记忆。
- 每个未来槽位乘以零初始化的 tanh 门后，与当前记忆共同组成 ACT 编码器记忆：

    [z0 + s1, q, s2, …, s12, M_current]

- ACT 解码器使用 50 个动作查询，输出 50×8 的归一化动作块，重叠块按年龄加权聚合。
- 训练目标为掩码动作 L1 损失，槽解相关为 detached（非反传）辅助项。

## 3. 实验设计：数据集、基准与对比方法

- **基准（Benchmark）**：UniVTAC 模拟基准（UniVTAC 是统一视觉-触觉操作数据生成、学习与基准测试平台），论文使用其中发布的 ACT 任务检查点，记为 UniVTAC-ACT*。
- **任务设置**：共 7 个接触丰富操作任务：
  - Put Shelf、Pull Out Key、Lift Bottle、Insert HDMI、Insert Hole（头相机）
  - Insert Tube、Lift Can（头+腕双相机）
  - 所有任务均使用左右双触觉流。
  - 训练集为 0–39 或 0–49 集，评估用 50–99 集，每种条件 50 次 rollout。
- **对比方法 / 条件**：
  1. **UniVTAC-ACT***：基准策略（无未来信息）。
  2. **AFM Oracle**：训练和评估均读取 oracle 未来，使用不对称路由。
  3. **IFM**：仅将路由改为模态隔离，其余与 AFM Oracle 相同。
  4. **AFM Forced-Zero**：使用 Oracle 训练好的检查点，但评估时将所有未来记忆槽置零。
  5. **AFM Zero-Train**：训练与评估时均从未读取未来 HDF 数据，注入 12×512 零张量。

## 4. 资源与算力

- **GPU**：两块 NVIDIA RTX 4090 D（24 GB）。
- **训练配置**：每个模型训练 2000 个优化步；per-GPU 微批大小 1，梯度累积 8，有效批大小 16。
- **优化器**：AdamW，学习率 1e-5，权重衰减 1e-4；门参数学习率 1e-3；余弦退火至 1e-6；梯度裁剪 1.0。
- **其他**：FP32 训练（无 AMP）；checkpoint 每 500 步保存，报告结果均使用第 2000 步。
- **软硬件环境**：Ubuntu 20.04.6，Intel i9-14900K，128 GB RAM，驱动 570.133.20，Python 3.10.12，PyTorch 2.7.0+cu128，Isaac Sim 4.5.0，Isaac Lab 0.41.3。

## 5. 实验数量与充分性

- **实验规模**：
  - 7 个任务 × 5 种条件（含基线） = 35 组主实验，每组 50 次 rollout，共 350 次评估 rollout。
  - 额外包含 3 组消融对比（Zero-Train vs Forced-Zero vs Oracle）。
- **公平性设计**：所有 AFM 系列条件共享相同的 50 行 episode/reset 映射、外部评估器、预处理、归一化、时间聚合、rollout 视界、早停设置、相机约定和不可变的厂商成功判定谓词；唯一允许的差异是检查点与为表达指定未来信息条件所需的最小适配器。
- **充分性评价**：实验设计在**控制变量上非常严谨**——IFM 与 AFM 的差异仅在于路由矩阵，Zero-Train / Forced-Zero 分别从训练端和评估端隔离未来信息的贡献，形成了比较完整的论证闭环。但每个任务仅 50 次 rollout，部分任务（如 Insert Hole、Lift Bottle）成功率处于个位数百分比，统计波动较大，结论的稳健性有待更多随机种子验证。

## 6. 论文的主要结论与发现

- **核心结果**（7 任务平均成功率）：

| 条件 | 成功率 |
|---|---|
| UniVTAC-ACT* | 14.9% |
| AFM Zero-Train | 20.0% |
| IFM | 23.7% |
| AFM Forced-Zero | 19.4% |
| **AFM Oracle** | **32.0%** |

- **主要发现**：
  1. **不对称视觉→触觉路由优于完全模态隔离**：AFM（32.0%）比 IFM（23.7%）高出 8.3 个百分点。即使模态 token 之后在 ACT 编码器内仍可互相注意力交互，显式的不对称融合依然带来收益，说明接口层的信息组织方式不可被下游自注意力完全取代。
  2. **策略确实在利用测试时的未来信息**：Oracle 检查点在 Forced-Zero 评估下从 32.0% 降至 19.4%，证明性能提升来自真实读取的测试时未来内容，而非新增模块的附带收益。
  3. **无未来信息时策略路径依然稳健**：AFM Zero-Train（20.0%）和 Forced-Zero（19.4%）均超过 UniVTAC-ACT*，说明 AFM 兼容的策略路径本身也具有竞争力。
  4. **任务层面差异**：Put Shelf 和 Pull Out Key 最能体现未来内容的行为价值（54%/54%）；Insert Tube 的收益主要体现在训练阶段（Oracle 与 Forced-Zero 均为 42%）；Insert Hole 是唯一 IFM 最高的任务，但所有条件都接近成功率下限。

## 7. 优点

- **问题意识清晰**：准确识别出 WAM 评估中“预测质量”与“接口质量”纠缠的问题，并据此提出解耦研究的框架。
- **实验设计巧妙**：OVTF 使用验证成功轨迹作为 oracle，在保证未来物理可执行性的前提下隔离接口变量；Forced-Zero 和 Zero-Train 两个控制条件构成了完整的因果推理链。
- **对比公平性高**：IFM 与 AFM 仅差路由矩阵，严格控制了记忆预算、优化预算、数据来源等所有可能混淆因素。
- **结论具有可迁移性**：证明了显式的不对称跨模态路由而非放任下游自注意力自行组织，对世界行动模型设计具有直接指导意义。

## 8. 不足与局限

- **实验覆盖有限**：仅模拟环境（UniVTAC），未验证真实机器人场景；模拟中的触觉观测与实际物理传感器存在 sim-to-real 差距。
- **统计效力受限**：每任务仅 50 次 rollout，低成功率任务（如 Insert Hole 4%、Lift Bottle 16%）的差异可能落在噪声范围内，未报告多次随机种子的方差。
- **Oracle 前提较强**：OVTF 依赖“成功的未来轨迹”这一特权信息来源，实际部署中不存在 oracle，从 OVTF 结论到端到端学习 WAM 的推广仍需验证。
- **AFM 设计中的手工归纳偏置**：相位锚点（4 个固定值）、高斯带宽（0.18）、跨触觉阻断等均为人工设定，缺乏敏感性分析。
- **未充分探索设计空间**：未测试更细粒度的路由方案（如部分跨触觉访问、可学习的路由权重），不对称路由的最优性缺乏更全面的搜索证据。
- **任务类型局限**：7 个任务均为单对象、近桌面尺度操作，未覆盖更复杂的双手长程操作或非刚体操作。
