## 摘要
视觉语言模型（VLM）在语义理解上表现强大，但在度量空间推理方面仍不可靠，特别是当查询需要比较同一物体类别的多个实例时。我们通过最近实例距离查询（CIDQ）来研究这一问题，其中模型必须识别出与唯一参考物体最近的可见候选者，并估计它们之间重力对齐的地面平面距离。我们提出了SPATIALQUERY，一个用于从单个RGB图像进行CIDQ推理的免训练框架，以及SPATIALQUERY-1M，一个包含来自200个室内场景的超过一百万个仅含RGB问答对的基准测试。SPATIALQUERY恢复实例级的度量几何，并通过场景立方化将其转换为规范鸟瞰图，该鸟瞰图将物体表示为大小均匀、类别编码的块，以强调它们在地面平面上的相对位置。我们进一步提出不确定性感知思维链（UA-CoT）提示方法，该方法将几何推导出的每实例不确定性纳入VLM推理过程。在无需任务特定微调或架构修改的情况下，SPATIALQUERY与Qwen3-VL-8B搭配取得了0.259米的Floor-MAE、90.5%的Unc-Acc@0.3米以及84.18%的邻近决策准确率，优于微调的空间专家模型、通用视觉语言模型和闭源前沿模型。代码、基准资源和交互式演示可在 https://namhai1810.github.io/SpatialQuery/ 获取。

## Abstract
Vision-language models (VLMs) achieve strong semantic understanding but remain unreliable in metric spatial reasoning, particularly when queries require comparing multiple instances of the same object category. We study this problem through the Closest-Instance Distance Query (CIDQ), where a model must identify the nearest visible candidate to a unique reference object and estimate their gravity-aligned floor-plane distance. We introduce SPATIALQUERY, a training- free framework for CIDQ reasoning from a single RGB image, together with SPATIALQUERY-1M, a benchmark containing over one million RGB-only question-answer pairs from 200 indoor scenes. SPATIALQUERY recovers instance-level metric geometry and transforms it into a canonical Bird's-Eye View through Scene Cubifying, which represents objects as uniformly sized, category-coded blocks to emphasize their relative floor- plane locations. We further propose Uncertainty-Aware Chain-of-Thought (UA-CoT) prompting, which incorporates geometry- derived per-instance uncertainty into the VLM reasoning process. Without task-specific fine-tuning or architectural modification, SPATIALQUERY with Qwen3-VL-8B achieves a Floor-MAE of 0.259 m, an Unc-Acc@0.3 m of 90.5%, and a proximity-decision accuracy of 84.18%, outperforming fine-tuned spatial specialists, general-purpose VLMs, and closed-source frontier models. Code, benchmark resources, and an interactive demo are available at https://namhai1810.github.io/SpatialQuery/.

# SPATIALQUERY：视觉语言模型中基于几何的多实例空间推理基准测试 — 详细论文总结

## 1. 核心问题与整体含义（研究动机与背景）

- **核心问题**：视觉语言模型（VLM）在语义理解上表现强大，但在度量空间推理（metric spatial reasoning）方面仍不可靠，尤其当查询需要**比较同一物体类别的多个实例**并选出最近者时。作者将这一场景形式化为“最近实例距离查询”（Closest-Instance Distance Query, CIDQ），要求模型同时完成三类子任务：
  1. 完整且无重复地检测并聚合所有候选实例；
  2. 在所有候选中选出与唯一参考物体最近的实例；
  3. 估计二者之间的重力对齐（gravity-aligned）地板平面距离。
- **现有方法的不足**：
  - 已有基准（如SpatialBench、VSR等）主要针对固定物体对的距离/关系推理，未涵盖可变基数的候选集合、最近实例选择与几何不确定性的联合评估；
  - 从单张透视RGB图像进行水平几何推理存在固有的视角偏差、透视畸变与物体高度差异，导致“视觉上相似、物理距离不同”的问题；
  - 单目几何重建本身充满不确定性，但现有空间推理系统通常将深度估计视为确定性输入，未显式传播不确定性。
- **整体意义**：该工作为VLM的多实例、度量级空间推理建立了大规模基准与无需训练的推理框架，推动了可度量、可验证的空间理解能力在具身AI与辅助系统中的应用。

## 2. 论文提出的方法论

### 2.1 核心思想
SPATIALQUERY 是一个**免训练（training-free）**的端到端推理框架，核心思路是将单目图像重建出的实例级度量几何转化为一种任务对齐的**规范鸟瞰图（Canonical BEV）**表达，并利用**几何推导的不确定性**指导VLM的推理过程，从而实现对CIDQ问题的可靠回答。

### 2.2 整体流程（五阶段流水线）

**Phase I：语义接地与场景解析**
- 使用 Qwen-VL 解析自然语言查询，提取候选类别 Cq、参考类别 Cr 以及（T2任务中的）阈值 τ；
- 使用 GroundingDINO 定位所有可见候选实例与参考实例，通过类内非极大值抑制确保参考实例唯一；
- 使用 SAM 将检测框转换为实例级掩码。

**Phase II：度量几何重建**
- 使用 Depth Pro 预测稠密度量深度图 D̂ 和相机内参矩阵 K̂；
- 通过深度派生的地平线行估计相机俯仰角 ϕ̂；
- 将每个实例掩码内的有效像素反投影为相机坐标系下的度量点云。

**Phase III：鲁棒细化与不确定性建模**
- **自适应深度尺度**：利用中位数和中位数绝对偏差（MAD）定义实例自适应深度尺度；
- **主导深度模式选择**：通过一维RANSAC选择主导深度模式，去除背景和边界离群值；
- **鲁棒地板平面定位**：对过滤后的点云计算坐标方向中位数，经俯仰角校正后投影到地板平面，得到重力对齐的度量坐标 ĝi；
- **地板平面几何离散度**：计算过滤点云在地板平面上的协方差迹的平方根，得到实例级不确定性 σ_BEV_i，作为几何可靠性代理。

**Phase IV：场景立方化（Scene Cubifying）与BEV抽象**
- 将细化后的地板平面坐标渲染到 512×512 重力对齐的顶视图画布上；
- 所有实例以统一尺寸、类别编码的立方体块呈现，参考实例用对比边框高亮；
- 该抽象**抑制了外观、透视和物体尺度变化**，保留候选与参考之间的相对布局关系；
- 像素距离仅作视觉上下文，所有数值距离和不确定性均从底层坐标直接计算。

**Phase V：不确定性感知思维链（UA-CoT）提示**
- 将BEV图像与结构化实例几何信息（每实例的类别、坐标、不确定性）组合成提示，注入VLM；
- VLM计算所有候选到参考的距离并选出最小者，得到预测最近距离 d̂q；
- 通过候选与参考不确定性的根方和（root-sum-square）聚合成查询级不确定性 σq，并以“d̂q ± σq”的形式输出；
- T2阈值任务直接以 d̂q ≤ τ 给出二值判断。

## 3. 实验设计

### 3.1 数据集与基准构建
- **SPATIALQUERY-1M**：从 MM-Spatial 的室内子集（源自 CA-1M，含超1000个室内场景、439K标注物体）出发构建，涵盖200个室内场景、73,924帧，最终生成 **1,064,022 个仅RGB问答对**：
  - T1距离估计：659,786条（62.0%）；
  - T2邻近决策：404,236条（38.0%），阈值 τ ∈ {0.5, 1.0, 1.5, 2.0, 3.0} 米；
  - 覆盖315个物体类别，地面真实距离均值1.52米、中位数1.15米。
- **四阶段构建流水线**：帧过滤（结构资格）、GPT-4o零样本可见性验证（阈值0.7）、GroundingDINO几何细化（Hungarian匹配）、空间合成（生成QA对与度量标签）。真实深度和相机参数仅在离线基准构建中使用，测试时模型仅接收RGB图像与自然语言查询。

### 3.2 评估协议

## 6. 主要结论与发现

1. **训练无关的几何接地可超越专用模型**：SPATIALQUERY w/ Qwen3-VL-8B 在T1上达到 Floor-MAE 0.259 m（较最强专用基线降低27.5%），Acc@0.2m 58.50%（较最优专用基线提高16.5个百分点）；T2准确率84.18%，超过最强微调专家8.14个百分点、闭源前沿模型18.94个百分点。
2. **几何推导的不确定性是有效信号**：结合σq后，Unc-Acc@0.2m 从58.50%提升至87.50%，Unc-Acc@0.3m 达90.50%；高离散子集Floor-MAE（0.349m）显著高于低离散子集（0.218m），表明σq有助于识别困难查询。
3. **骨干选择敏感但方向一致**：换用Qwen2.5-VL-3B后Floor-MAE升至3.643m（数值离群值主导），但Acc@0.2m和Unc-Acc@0.3m仍较纯骨干分别提升5个和19.6个百分点——框架可移植但依赖足够指令遵循和数值推理能力。
4. **消融揭示互补机制**：UA-CoT单独使用会使Floor-MAE恶化至16.341m（结构化推理放大了不可靠几何），加入TC+MR后骤降至0.263m；进一步加入BEV Scene Cubifying后Acc@0.2m再提升4.5个百分点——**几何稳定化是结构化推理的前提，结构化推理放大几何接地的收益**。
5. **结构化推理不能修复全局错误**：单目深度在低纹理、反光、透明和严重遮挡区域仍会造成系统性偏差。

## 7. 优点

1. **任务设计具有创新性**：CIDQ将可变基数候选集聚合、最近实例选择与度量距离估计统一在一个任务中，填补了现有基准（多固定在预定义物体对）的空白；
2. **免训练框架实用性高**：无需微调或架构修改，即插即用，配合开放权重VLM即可超越闭源前沿模型；
3. **场景立方化抽象巧妙**：将透视RGB转换为规范重力对齐BEV，抑制外观/透视/尺度噪声，使VLM聚焦于任务关键的相对地板平面布局；且像素仅作视觉界面，距离始终从底层坐标计算，避免了BEV像素量化的精度损失；
4. **不确定性建模端到端传播**：从深度MAD-RANSAC到地板平面离散度再到查询级σq，将单目几何的不确定性系统性地纳入推理链，而非当作确定性输入；
5. **基准构建严谨**：四阶段流水线包含LLM可见性验证与独立2D检测的几何细化，并采用黑图sanity过滤与分层抽样，基准规模超百万级，覆盖315个类别；
6. **实验设计规范**：统一零样本协议、固定公共评估集、多组对比体系（纯VLM/闭源/微调专家）与详细消融相结合。

## 8. 不足与局限

1. **单目深度依赖**：框架对Depth Pro的深度质量高度敏感，低纹理、反光/透明表面、严重遮挡和全局深度偏差场景下仍不可靠；MAD-RANSAC可抑制局部离群点但无法恢复深度估计中缺失的信息。
2. **骨干能力瓶颈**：性能依赖VLM的指令遵循和数值推理能力，小型骨干（如Qwen2.5-VL-3B）会出现严重的数值离群值，使平均误差指标大幅恶化——框架具备可移植性但并非骨干无关。
3. **适用场景受限**：仅限静态、单层、室内环境单张RGB图像，未扩展到室外、多层建筑、动态物体或多视角观测。
4. **基准偏差风险**：数据源于CA-1M室内场景，物体类别分布与房间类型偏向常见室内配置；LLM可见性打分与GroundingDINO的检测质量可能引入系统性的标注偏差。
5. **不确定性解释边界**：σq只是“可靠性代理”，论文明确说明它不是校准后的概率置信区间，使用时需注意其统计含义。
6. **算力与复现细节不足**：未报告总GPU时数、推理延迟、基准构建的计算成本；RANSAC参数（λMAD、Kiter）等关键超参数仅指向补充材料，主文中缺少敏感性分析。
7. **评估方式局限**：T2阈值为固定离散集合（0.5–3.0m），未评估连续阈值下的决策性能；T1的Floor-MAE易受极端离群值主导，与容差类指标在较小骨干上出现排序不一致的现象，需结合多个指标进行综合判断。
