## 摘要
从视频序列预测未来状态是自主机器人系统面临的关键挑战，也是世界建模的基本目标。先前在像素级别运行的生成方法不可避免地过度强调与任务无关的细节，导致计算开销过大。虽然基于潜在空间的方法试图通过直接预测特征来缓解这一问题，但状态到任务映射对重型解码器的持续依赖仍然是计算瓶颈。在这项工作中，我们提出了无解码器特征预测（DF$^3$），这是一种新颖的框架，完全在潜在空间内建模世界演化并直接推导任务输出，从而彻底消除了对解码器的需求。具体来说，DF$^3$ 将可学习的空间查询注入冻结的视觉基础模型的终端块中，直接提取未来状态表示。通过采用轻量级、统一的运动感知上下文融合（MACF）机制，该机制将粗略光流扭曲与细粒度潜在互相关无缝集成，这些查询与历史令牌表示交互，以显式对齐并预测下一帧的特征。随后，一组专门的任务查询探测这些预测特征以用于下游任务。在公共基准和机器人模拟器零样本部署上的大量实验表明，DF$^3$ 在实现与最先进方法相当性能的同时，为集成感知和控制提供了卓越的效率和灵活性。

## Abstract
Forecasting future states from video sequences is a critical challenge for autonomous robotic systems and a fundamental objective of world modeling. Prior generative methods operating at the pixel level inevitably overemphasize task-irrelevant details, leading to prohibitive computational overhead. While latent-based approaches attempt to mitigate this by predicting features directly, the persistent reliance on heavy decoders for state-to-task mapping remains a computational bottleneck. In this work, we propose Decoder-Free Feature Forecasting (DF$^3$), a novel framework that models world evolution entirely within the latent space and directly derives task outputs, completely eliminating the need for a decoder. Specifically, DF$^3$ injects learnable spatial queries into the terminal blocks of a frozen vision foundation model to extract future state representations directly. By employing a lightweight, unified Motion-Aware Context Fusion (MACF) mechanism that seamlessly integrates coarse flow warping with fine-grained latent cross-correlation, these queries interact with historical token representations to explicitly align and forecast the feature of the next frame. Subsequently, a specialized set of task queries probes these forecasted features for the downstream task. Extensive experiments on public benchmarks and zero-shot deployment in a robotic simulator demonstrate that DF$^3$ achieves performance comparable to state-of-the-art methods while offering superior efficiency and flexibility for integrated perception and control.

- **现有方法的瓶颈**：
  - **像素级生成方法**（如视频生成模型）：在原始像素空间合成未来帧，计算开销巨大，且过度关注与任务无关的高频细节（纹理、光照），下游还需额外的感知解码器，延迟高、效率低。
  - **潜在空间方法**（如 DINO-WM、DINO-Foresight）：在语义特征空间预测未来特征，避免了像素级冗余，但依然依赖重型空间-时间解码器来重建/对齐特征，且需要额外的任务解码器将预测特征映射为任务输出，计算瓶颈仍然存在。
- **研究问题**：能否在冻结的视觉基础模型（VFM）编码器内部**完全完成特征预测与任务解码**，彻底去除解码器？

## 2. 方法论：DF³ 框架

### 2.1 核心思想
- **无解码器设计**：利用预训练 ViT（DINOv3-ViT-B/16，冻结权重），将其终端块（L2）作为可交互的特征处理器。通过向终端块注入**可学习空间查询**，直接输出未来帧的潜在特征；再注入**任务查询**，直接从预测特征中提取任务输出（如语义分割掩码）。
- **三层结构**：历史帧经过浅层（L1）提取上下文特征 → 预测查询注入终端块并引入 MACF 融合时序 → 任务查询探测预测特征。

### 2.2 关键技术细节

**(1) 结构化查询注意力（Structured Query Attention）**
- 在终端块自注意力中引入非对称注意力掩码 M：
  - **上下文令牌**（i ≥ Nq）可以互相自由关注，但**禁止关注预测查询**（防止信息泄漏）；
  - **预测查询**（i < Nq）可以关注所有令牌（包括上下文与自身）。
- 公式：$M_{i,j} = 0$ 表示掩码（屏蔽），$M_{i,j} = 1$ 表示允许关注。

**(2) 运动感知上下文融合（MACF）机制**——统一轻量级时序对齐模块：
- **Flow-based Warp Branch（流扭曲分支）**：
  1. 从空间预测查询 $q_{\text{patch}}$ 预测稠密潜在光流场 $Δp$；
  2. 将光流作用于最近历史特征图，得到粗略对齐的未来特征 $\tilde{f}_{\text{warp}}$；
  3. 计算 $\tilde{f}_{\text{warp}}$ 与当前查询的差值作为建议更新方向 $M_{\text{warp}}$。
- **Cross-Correlation Branch（潜在互相关分支）**：
  1. 在前一帧特征 $f_{T-1}$ 的局部邻域窗口（半径 r）内，对当前帧特征 $f_T$ 做软匹配（余弦相似度 + softmax）；
  2. 计算历史语义运动 $V_{\text{hist}}$（实际特征 − 软匹配特征）；
  3. 通过 MLP 得到运动注入 $M_{\text{xcorr}}$。
- **动态融合**：利用 sigmoid 门控 G 将 warp 和 xcorr 两支路的残差动态融合到查询中，得到最终预测特征。
- **全局前缀令牌**：使用轻量级时间外推器，基于历史前缀查询的差分预测其演化。

**(3) 训练目标**
- 采用**特征级监督**（无任务联合训练）：
  - 余弦相似度损失（方向对齐） + Huber 损失（幅度稳定）：
    $L_{\text{sim}} = \mathbb{E}_t \left[ 1 - \cos(\hat{F}_{L1}(I_{t+1}), F_{L1}(I_{t+1})) + \lambda_{\text{huber}} \cdot \text{Huber}(\hat{F}, F) \right]$；
  - 对 patch 令牌和前缀令牌均计算损失，保证整体场景表示。

### 2.3 算法流程（文字说明）
1. 输入 T 个历史帧，每个帧通过冻结 ViT 的浅层 L1 提取上下文特征（patch + prefix tokens）；
2. 将预测查询与所有上下文特征连接，送入冻结 ViT 终端块，注意力掩码保证引入查询不污染上下文；
3. 终端块输出的查询特征经 MACF 机制融合两帧之间的运动信息（光流粗对齐 + 互相关细匹配），更新为未来帧特征；
4. 将预测特征重新作为输入，与任务查询一起再次送入终端块，任务查询聚合预测特征后经轻量 MLP 头输出语义分割结果。

## 6. 主要结论与发现

- **性能-效率平衡**：DF³ 在短期预测中达到 69.9 mIoU / 68.7 MO-mIoU（略低于 DINO-Foresight 的 71.8/71.7），但显著降低计算开销（FLOPs ↓36%、延迟 ↓70% 至 292ms、峰值显存 ↓67% 至 3.1GB、参数 ↓41%）；
- **MACF 机制有效性**：单一融合方式（Concat/Attn/Warp/Xcorr）均不及完整 MACF，表明光流粗对齐与互相关细匹配的互补性是效能的来源（Concat 59.9 → 完整 69.9 mIoU）；
- **搜索半径敏感性**：半径 8 的引入对捕捉快速运动（车辆）至关重要，但过大的半径（如 16）会引入噪声，导致轻微性能下降；
- **零样本跨具身泛化**：仅在 Cityscapes 车载视角训练的模型，能直接支撑四足机器人在仿真器中的轨迹规划（与 Oracle 轨迹高度对齐），证明预测特征蕴含本质运动语义，具备可迁移性。

## 7. 优点与亮点

- **方法创新性**：首次实现**完全无解码器**的潜在空间特征预测+任务输出一体化框架，理念新颖，结构简洁；
- **效率优势显著**：将延迟和显存压缩到实际部署可接受水平（约 292ms/帧），为实时系统提供可能性；
- **冻结骨干 + 轻量附加模块**：严格保持骨干冻结，训练开销小、部署灵活，预测查询与任务查询解耦训练，可独立复用；
- **MACF 机制精巧**：将经典光流与特征互相关统一在轻量级模块中，作为冻结网络的时间建模先验，兼具简洁性与物理可解释性；
- **验证范式完整**：不仅做了标准数据集评测，还通过仿真器零样本部署验证了实际机器人应用价值，说服力较强。

## 8. 不足与局限

- **性能差距**：相比 DINO-Foresight，mIoU 下降约 1.9 个点（短期）、1.6 个点（中期），且 MO-mIoU 差距略大（68.7 vs 71.7），表明运动目标对齐仍有改进空间；
- **空间细节损失**：预测特征存在边界粗糙、薄结构锐度下降的通病，是冻结特征空间下采样的固有折衷；
- **无动作条件**：框架仅支持观测驱动的预测，无法建模“条件动作 → 未来状态”的因果映射，限制了闭环控制/规划场景的应用；
- **评测范围有限**：只在 Cityscapes 上量化，未覆盖多样化驾驶场景（天气、夜间、不同传感器配置），与 SOTA 的对比基线也偏少；
- **跨具身部署缺乏量化指标**：MATRiX 实验仅提供定性可视化，没有成功率、碰撞率等可量化导航指标；
- **资源披露不完整**：未报告训练总时长、功耗等关键数据，难以全面评估训练成本。
