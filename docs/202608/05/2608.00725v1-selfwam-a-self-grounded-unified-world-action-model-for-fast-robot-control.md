## 摘要
世界动作模型（WAM）通过联合建模动作和未来观察来改进机器人策略学习。然而，仅基于任务提示和观察上下文进行未来预测，可能会捕捉到一般的任务进展，而不是执行动作所产生的特定于动作的后果。我们引入了SelfWAM，一种基于模态专用混合变换器（MoT）架构的统一自接地WAM，它联合预测动作、动作条件下的未来RGB帧和机器人自掩码，从而将未来预测扎根于机器人的可见身体及其动作引起的运动。在联合训练期间，SelfWAM允许未来视觉查询关注演示动作的干净副本，将视频分支转变为特定于动作的后果模型，同时保留仅基于动作的快速推理路径不变。为了将视频学习集中在动作相关的视觉变化上，我们对未来的机器人自掩码预测使用了特定于提示的目标，这消除了外观细节，并提供了一个目标，其时间演化与条件动作紧密耦合。总之，干净动作条件和未来自掩码监督使未来预测更直接地反映执行动作如何改变机器人的可见运动和周围场景。在RoboTwin 2.0和真实世界操作任务上的实验表明，SelfWAM产生更动作敏感的未来并保持快速策略推理，同时提高策略性能。

## Abstract
World Action Models (WAMs) improve robot policy learning by jointly modeling actions and future observations. However, conditioning future prediction only on the task prompt and observation context risks capturing generic task progression rather than the action-specific consequences of the executed action. We introduce SelfWAM, a unified self-grounded WAM built on a modality-specialized Mixture-of-Transformers (MoT) architecture that jointly predicts actions, action-conditioned future RGB frames, and robot self-masks, thereby grounding future prediction in the robot's visible body and its action-induced motion. During joint training, SelfWAM allows future visual queries to attend to a clean copy of the demonstrated action, turning the video branch into an action-specific consequence model while leaving the fast action-only inference path unchanged. To focus video learning on action-relevant visual changes, we use prompt-specific objectives for future robot self-mask prediction, which removes appearance details and provides a target whose temporal evolution is tightly coupled with the conditioning action. Together, clean-action conditioning and future self-mask supervision make future predictions more directly reflect how the executed action changes the robot's visible motion and the surrounding scene. Experiments on RoboTwin 2.0 and real-world manipulation tasks show that SelfWAM produces more action-sensitive futures and preserves fast policy inference, while improving policy performance.

## 1. 论文的核心问题与整体含义

- **研究背景**：世界动作模型（World Action Models, WAM）通过联合建模动作和未来观测，将预训练视频先验引入机器人策略学习，是当前机器人操控领域的重要方向。以 FastWAM 为代表的方法证实，未来视频预测仅作为**训练阶段的辅助目标**即可带来显著性能提升，推理时可完全省略视频生成，从而保持快速闭环控制。
- **核心问题**：现有 WAM 的"观测条件化"未来预测存在根本缺陷——它只依赖当前观测和任务指令来预测未来帧，**不显式感知产生该未来的执行动作**。这导致视频分支学到的是通用任务进展（generic task progression）而非特定动作的因果后果。给定同一观测和不同动作，模型无法区分其视觉结果差异。
- **关键洞察**：一个"策略导向"的世界模型不仅应回答"接下来会发生什么"，还应回答"在某个具体动作下会改变什么、变化发生在哪里、机器人的身体如何参与这种改变"。这种**自接地**（self-grounded）的未来预测对操纵任务至关重要——同一观测往往对应多种可行动作，每种动作通向不同的未来。
- **解决思路**：论文提出 SelfWAM——一个自接地的动作条件化 WAM，通过（1）让未来视觉查询在训练时可关注**干净演示动作副本**，将视频分支变成"动作特定后果模型"；（2）引入**未来机器人自掩码预测**作为辅助目标，去除外观/背景变化，将学习信号聚焦于机器人自身的可见运动，使未来预测真正反映执行动作的因果后果。

## 2. 论文提出的方法论

**核心思想**：在 FastWAM 的模态特化混合变换器（MoT）双流架构上，增加一条**单向信息流**——将干净演示动作只暴露给未来视觉查询，同时保持动作策略路径与部署时一致。视频骨干通过两个输出提示（prompt）联合训练未来 RGB 预测和未来自掩码预测。

**关键技术细节**：

- **双流 MoT 架构**：包含预训练视频骨干（视频流）和轻量动作专家（动作流），通过混合注意力（mixed attention）耦合。动作专家参数从预训练视频专家插值初始化。
- **信息流设计**（训练阶段）——设 O 为当前上下文 token，Ã 为带噪未来动作 token，A 为干净动作 token，Ṽ 为带噪未来视觉 token：
  - Q_Ã → {O, Ã}：策略分支只依据当前上下文和自身带噪动作状态去噪，**无法获取干净动作或未来视觉信息**（防止目标泄漏）；
  - Q_Ṽ → {O, Ṽ, A}：未来视觉分支可关注干净动作副本，使预测显式条件于执行动作；
  - Q_A → {O, A}：干净动作仅与自身上下文交互。
  - 干净动作副本使用 t=0 时间步嵌入，与带噪动作共享语义和时序对齐；部署时完全省略该流。
- **自掩码预测**：同一演示生成两种世界模型训练实例——RGB 提示（预测未来 RGB）和自掩码提示（预测机器人分割掩码序列）。二者共享观测、指令、本体感觉、干净动作条件，仅输出提示和目标不同。自掩码目标为二进制机器人掩码，与 RGB 帧时间对齐、空间布局一致，采样比例为 9:1。
- **训练损失**：L = λ_act · L_act + λ_video · L_rgb/mask，其中 λ_act = λ_video = 1。动作损失只计算一次（RGB 实例），掩码实例仅贡献 L_mask。
- **推理路径**：快速控制模式仅编码当前观测，用轻量动作专家迭代去噪预测动作块，不实例化干净动作或未来视觉 token；可选世界模型回滚模式支持将候选动作插入干净路径，生成未来 RGB 或自掩码视频。

## 3. 实验设计

**数据集与场景**：

- **RoboTwin 2.0**：大规模双臂协调操纵基准，包含 50+ 任务。训练数据为 27,500 条演示（2,500 条干净环境 + 25,000 条强场景随机化）。分别在干净与随机化环境中评估，每任务 100 次回滚。模拟器提供逐相机精确机器人掩码。
- **真实机器人**：AgileX ALOHA 双臂平台，含约 17K episode、950 万转移数据的桌面操纵数据集。真实机器人自掩码由 RobotSeg 离线生成。四个任务：棕色杯子放到木架、黑笔插入蓝杯、黑鼠标放到灰鼠标垫、纸球放入桌面垃圾箱。

**对比方法**：

- VLA 基线：π0、π0.5；
- WAM 基线：Motus、GigaWorld-Policy、FastWAM。

**评估指标**：

- 策略性能：任务成功率（主要指标）+ 推理延迟；
- 未来预测质量：LPIPS、PSNR、FVD-I3D；
- 动作敏感性：WorldArena 的 Action Following 与三种 Raw Consistency 指标、方向性动作扰动、连续动作插值。

## 6. 论文的主要结论与发现

1. **策略性能提升**：RoboTwin 2.0 上 SelfWAM 平均成功率达 **92.62%**（干净 92.16% / 随机 93.08%），优于 FastWAM（91.84%）、Motus（87.84%）、GigaWorld-Policy（85.70%）、π0.5（79.75%）和 π0（62.16%）；随机化设置下提升更明显，表明自接地监督增强了对表现变化的鲁棒性。真实机器人上平均 95% 成功率，优于 FastWAM（85%）和 π0.5（90%）。
2. **未来预测更动作敏感**：LPIPS 从 0.0636 降至 0.0429，PSNR 从 29.24 升至 32.79，FVD-I3D 从 45.92 降至 34.55——动作条件化显著改善未来视频保真度。
3. **动作条件至关重要**：方向扰动实验中，无动作条件基线对动作变体几乎不变，SelfWAM 的预测按扰动方向移动并匹配真实运动趋势；连续插值实验显示响应连续且方向正确。
4. **推理开销不变**：action-only 延迟仅增加 0.97%，内存零增加，保持快速闭环控制能力。

## 7. 优点

- **精确的问题诊断**：准确识别出 FastWAM 类方法的根本缺陷——未来预测缺失动作条件，将其从"被动观测者"转变为"主动参与者"，角度新颖且击中要害。
- **优雅的信息流设计**：通过"干净动作副本仅暴露给未来视觉查询"的单向线路，在训练时实现动作条件化，推理时完全省略该路径。干净/带噪路径一致性分析（σ=0 时最大 NRMSE 约 1×10⁻⁵，余弦距离约 6×10⁻¹¹）证明了设计的一致性。
- **自掩码监督的创新性**：将机器人自掩码作为未来预测目标，从 RGB 目标中分离出"外观/背景噪声"，集中学习与动作紧密耦合的自身运动，是对结构化视觉监督的有价值补充。
- **兼容性强的架构**：不改变策略输入格式、不增加推理开销、不要求部署时分割模型参与，直接继承 FastWAM 的高效策略接口，易于集成到现有工作流。
- **实验设计全面**：从仿真到真实、从策略性能到视频质量、从定量指标到可视化分析，多维度验证。

## 8. 不足与局限

- **交互建模缺失**：论文自述明确承认 SelfWAM 不显式建模接触力、力觉或遮挡隐藏的交互，对接触丰富的任务（如精密装配）监督信号可能不足。
- **真实实验规模有限**：仅 4 个任务、每任务 10 次试验，成功率高但样本量小，难以评估统计显著性和泛化边界；各基线在部分任务上差异较小（如 Pen → Cup 和 Ball → Bin 上三方法分数相同），区分度有限。
- **计算门槛高**：64×A800 训练 30 小时约等于 1,920 GPU-hours，复现成本高；5B 参数骨干对资源受限实验室不友好。
- **未来预测评估偏差风险**：参考导向指标（LPIPS/PSNR/FVD）衡量的是"与记录未来相似"而非"对动作敏感"，论文仅用 1% 子集评估，且这种评估对离线策略演示可能存在乐观偏差。WorldArena 的 Photometric Raw Consistency 指标在完整模型中反而轻微下降（表 S3）。
- **消融发现需深究**：表 4 显示单独加动作条件（无自掩码）时策略性能实际上比 FastWAM 略降（90.80% vs 91.84%），表明动作条件本身并非无条件有益，其价值需要通过自掩码监督配合实现，论文对这种交互效应解释有限。
- **掩码噪声未分析**：真实场景使用 RobotSeg 离线生成掩码，分割错误会作为噪声注入训练目标，但论文未分析分割质量对性能的影响。
