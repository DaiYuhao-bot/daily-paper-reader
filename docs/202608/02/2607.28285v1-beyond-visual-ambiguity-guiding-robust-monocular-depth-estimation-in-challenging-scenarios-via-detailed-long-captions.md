## 摘要
单目深度估计（MDE）面临非朗伯表面和恶劣天气条件的挑战，这源于单图像有限信息中固有的视觉模糊性。现有工作通过图像修复或增强等方式孤立地处理这些问题，带来的鲁棒性提升有限。语言作为视觉的有力补充模态，已被证明通过详细的长标题能够增强视觉语言模型（VLMs）的视觉感知能力。然而，先前的语言集成MDE方法由于文本输入短、信息有限、全局文本特征学习粗糙以及深度解码过程中语言指导不足，未能充分利用这一潜力。为解决这些局限性，我们提出了CapDepth，一种新颖的鲁棒MDE框架，利用详细长标题的指导来缓解挑战性场景中的视觉模糊性。首先，我们设计了一种详细长标题输入模板，明确传达多个原子句子之间丰富的空间关系。其次，引入动态标题编码器，通过渐进式掩码注意力提取细粒度的深度相关文本特征。最后，我们提出一种文本自适应解码器，通过稳定的自适应层归一化利用文本特征引导增强的深度解码。大量实验验证了CapDepth的有效性，其性能优于最先进的方法，在非朗伯表面上深度误差降低25.0%，在恶劣天气条件下降低22.0%。

## Abstract
Monocular depth estimation (MDE) faces challenges with non-Lambertian surfaces and adverse weather conditions due to the visual ambiguities inherent in single-image limited information. Existing works address them in isolation via image inpainting or augmentation, yielding limited robustness gains. Language, as a powerful complementary modality to vision, is demonstrated to enhance the visual perception capabilities of vision-language models (VLMs) via detailed long captions. However, prior language-integrated MDE methods fail to fully harness this potential due to short text input with limited information, coarse global text feature learning, and limited language guidance during depth decoding. To address these limitations, we propose CapDepth, a novel framework for robust MDE that leverages guidance from detailed long captions to alleviate visual ambiguities in both challenging scenarios. First, we design a detailed long caption input template that explicitly conveys rich spatial relationships among multiple atom sentences. Second, a dynamic caption encoder is introduced to extract fine-grained depth-relevant text features via progressive masked attention. Finally, we propose a text-adaptive decoder that guides enhanced depth decoding with text features via stable adaptive layer normalization. Extensive experiments validate the efficacy of CapDepth, which outperforms state-of-the-art methods, achieving depth error reductions of 25.0% on non-Lambertian surfaces and 22.0% under adverse weather conditions.

## 2. 方法论：核心思想、关键技术细节

### 2.1 整体框架（CapDepth）

给定输入图像 I ∈ R^{H×W×3} 及其对应标题 C，目标是预测稠密深度图 D ∈ R^{H×W}。框架包含三个核心组件，分别对应三个关键问题：

| 关键问题 | CapDepth 的解决方案 |
|---------|-------------------|
| ① 文本输入应采用什么形式？ | 详细长标题输入模板 |
| ② 如何提取有效的文本特征？ | 动态标题编码器 |
| ③ 文本特征如何有效指导深度预测？ | 文本自适应解码器 |

总体流程：输入图像经冻结的 VAE 编码为潜变量，文本经动态编码器提取细粒度特征；二者共同输入扩散 U-Net（时间步 t=0）进行初步交互；U-Net 上采样层提取多尺度金字塔特征，拼接后送入文本自适应解码器完成深度回归。

### 2.2 详细长标题输入模板

- **原子句模板**：`"O_A {空间关系短语} O_B."`（如："杯子在门的前面"），其中空间关系短语涵盖"behind""in front of""above""below""to the left of""to the right of"等。
- **构造方式**：将多个原子句无缝堆叠，形成详细长标题，显式编码物体间的空间关系。
- **生成方式**：使用 InternVL2.5-78B VLM 生成严格遵循模板的标题。
- **与现有方法的对比**（Tab. 1）：空间词占比 0.34（VPD 为 0.02，WorDepth 为 0.09）；空间词/物体词比率 3.06（WorDepth 仅 0.36）；平均词数 45.25（VPD 5.30，WorDepth 8.86），显著高于先前方法。

### 2.3 动态标题编码器

- **动机**：提取全局 [CLS] 特征会丢失细粒度空间信息。
- **技术细节**：
  - 首先用 CLIP 提取标题 token 特征 z_C ∈ R^{n×d_C}；
  - 通过 MLP + Sigmoid 预测各 token 的深度相关性分数，扩展为 n×n 软掩码 M；
  - 经过 L=6 个**渐进掩码查询块（progressive masked querying blocks）**，按式 (1) 迭代：
    - Q⁽ⁱ⁾ = softmax( (Q⁽ⁱ⁻¹⁾W_Q (z_C W_K)ᵀ ⊙ M) / √d_k ) · z_C W_V
  - 初始查询 Q⁽⁰⁾ = z_C，最终输出 Q⁽ᴸ⁾ 为细粒度深度相关文本特征。
- **可视化验证**（Fig. 3）：模型自适应地赋予物体词（如"bottle""door"）和空间短语（如"in front of"）更高权重。

### 2.4 文本自适应解码器

- **动机**：U-Net 特征本质是噪声预测特征，与深度估计所需的几何推理之间存在特征差距。
- **技术细节**：
  - 文本特征 Q⁽ᴸ⁾ 经平均池化和 MLP 产生调制参数 a 和 b；
  - 通过**稳定自适应层归一化（SAdaLN）**与视觉特征 F 融合（式 2）：
    - F̃ = LayerNorm(F) · a + b
  - 融合后的特征经 2×2 反卷积上采样，重复 N=3 次，最后经 3×3 卷积头回归深度图。
- **训练稳定性问题与正则化**：
  - 仅用尺度不变损失 L_ssi 训练时出现收敛瓶颈（损失平台期，2500–15000 次迭代）；
  - 原因分析：不同输入文本导致 a、b 波动大，使 F̃ 通道方差显著增大；
  - 解决方案：约束 F̃ 服从标准正态分布，即最小化 N(b, a²I) 与 N(0, I) 之间的 KL 散度（式 3）：
    - L_reg = −log|a| + (a² + b²)/2 − 1/2
  - 总损失（式 4）：L = L_ssi + λL_reg，其中 λ=1×10⁻³。

## 6. 主要结论与发现

1. **详细长标题显著提升鲁棒 MDE 性能**：在非朗伯表面上 AbsRel 降低 25.0%（对比 DAV2），在恶劣天气下降低 22.0%，优于所有对比方法。
2. **三个组件均有效**：
   - 详细长标题模板提供了远超短文本的空间信息密度（空间词占比 0.34 vs. 0.09）；
   - 动态标题编码器通过渐进掩码注意力提取细粒度深度相关特征，显著优于直接使用 CLIP 特征（δ₁ 提升 9.6%）；
   - 文本自适应解码器的 SAdaLN 桥接了 U-Net 噪声预测特征与几何推理之间的差距（去除后恶劣天气 AbsRel 增加 54.2%）。
3. **语言指导具有通用性**：同一框架同时缓解两类视觉模糊性，克服了场景特定方法无法跨场景迁移的局限。
4. **训练稳定性可通过分布正则化保证**：KL 散度正则化有效控制特征方差，促进收敛。
5. **模型对文本质量具有一定鲁棒性**：即便输入空间关系有误（50% 概率扰动），性能下降有限；但完全偏离模板的自由文本会明显削弱效果，验证了模板设计的重要性。

---

## 7. 优点

1. **问题定位精准**：明确指出现有语言集成方法的三大缺陷（短文本、粗特征、弱指导），并逐一提出针对性解决方案，逻辑严密。
2. **统一框架设计**：首次以语言为统一模态同时解决非朗伯表面和恶劣天气两类模糊性，克服了场景特定方法（inpainting、渲染增强）的碎片化问题。
3. **方法创新性**：
   - 将 VLM 中"详细长标题增强感知"的发现迁移至 MDE 任务；
   - 渐进掩码注意力机制实现了词级细粒度文本特征提取；
   - SAdaLN 结合 KL 正则化的设计兼顾了特征融合与训练稳定性，具有理论依据（附录含推导）。
4. **实验严谨性**：消融设计层次分明（组件→模板→文本质量→模块替代），交叉实验（Tab. 4）有力证明了方法对文本质量的鲁棒性而非依赖于特定模板。
5. **可视化分析丰富**：注意力权重可视化和原子句逐一删除法为方法的可解释性提供了直观证据。

---

## 8. 不足与局限

1. **语言覆盖单一**：仅探索了英文标题，未涉及多语言场景，作者在结论中也明确承认，跨语言泛化是未来工作方向。
2. **训练数据域限制**：仅在合成数据集（Hypersim、Virtual KITTI 2）上训练，尽管零样本测试表现良好，但在真实世界复杂场景中的表现仍有待验证。
3. **依赖 VLM 生成质量**：性能与标题生成模型的能力高度相关（Tab. B 中从 1B 到 78B 模型性能递增），实际应用中需要高性能 VLM，增加了系统复杂性和成本。
4. **推理效率**：基于扩散 U-Net 的方法延迟较高（342 ms，高于 WorDepth 的 79 ms），大规模实时应用受限。
5. **场景覆盖有限**：
   - 恶劣天气仅涵盖 foggy、cloudy、rainy 和 night-rain，未覆盖雪、冰雹、沙尘等极端天气；
   - 非朗伯表面主要针对透明和镜面物体，对其他反射表面（如金属）覆盖不足。
6. **标题生成约束较强**：模板强制使用有限的空间关系短语集合，限制了文本表达的多样性；若输入不严格遵循模板（如 VPD、WorDepth 风格文本），性能会下降。
7. **与现有 MDE 基础模型的结合方式**：方法以 VPD 为基线构建，未充分探索与更强基线（如 DAV2、Metric3D2）结合的潜力，可能限制性能上限。
