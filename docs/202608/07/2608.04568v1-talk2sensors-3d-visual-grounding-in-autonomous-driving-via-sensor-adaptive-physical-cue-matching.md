## 摘要
作为具身智能的关键能力，3D视觉定位（3DVG）主要在室内场景中借助RGB-D或点云输入进行研究，而现有的户外扩展大多仅依赖单目图像。这两种设置都不足以应对真实世界的户外感知，因为在户外感知中，异构传感器捕获的物理属性互补但各不相同，例如视觉纹理、3D几何和物体运动学，这些属性对于灵活且稳健的查询自适应定位至关重要，但尚未得到充分利用。为了弥合这一差距，我们引入了Talk2Sensors，这是第一个基于相机、LiDAR和4D雷达构建的多传感器3D视觉定位数据集。它包含8,682条语言指令和20,558个被指代目标，并带有与传感器特定物理线索明确对齐的多样化提示。此外，我们提出了TSFormer，一种基于Transformer的统一框架，用于自动驾驶中的语言引导3D视觉定位。TSFormer采用从粗到细的属性感知融合策略：语言路由属性采样器首先通过使用查询级语言线索调制传感器采样权重来执行粗略的文本条件特征检索，而后续的稀疏保持模态仲裁器模块执行细粒度的模态仲裁和文本引导细化，以确定精确的被指代空间位置。这种设计使得能够根据每个提示的语义要求对外观、几何和运动线索进行动态路由，防止密集模态淹没稀疏但关键的传感器信号。大量实验表明，TSFormer在多个基准测试中实现了最先进的性能：在Talk2Sensors上比最强基线提高了8.05 mAP，并迁移到单目Mono3DRefer基准测试，获得了53.05%的Acc@0.5。

## Abstract
As a key capability for embodied intelligence, 3D visual grounding (3DVG) has been predominantly studied in indoor scenes with RGB-D or point-cloud inputs, while existing outdoor extensions largely rely on monocular images alone. Both settings fall short of real-world outdoor perception, where heterogeneous sensors capture complementary yet distinct physical properties, such as visual texture, 3D geometry, and object kinematics, that are indispensable for flexible and robust query-adaptive grounding but remain under-exploited. To bridge this gap, we introduce Talk2Sensors, the first multi-sensor 3D visual grounding dataset built upon camera, LiDAR, and 4D radar. It contains 8,682 language instructions and 20,558 referred objects, with diverse prompts explicitly aligned with sensor-specific physical cues. Furthermore, we propose TSFormer, a unified Transformer-based framework for language-guided 3D visual grounding in autonomous driving. TSFormer adopts a coarse-to-fine property-aware fusion strategy: the Language-Routed Property Sampler first performs coarse text-conditioned feature retrieval by modulating sensor sampling weights with query-level linguistic cues, while the subsequent Sparse-Preserving Modality Arbiter module conducts fine-grained modality arbitration and text-guided refinement to determine the precise referred spatial location. This design enables dynamic routing of appearance, geometry, and motion cues according to the semantic requirements of each prompt, preventing dense modalities from overwhelming sparse but critical sensor signals. Extensive experiments demonstrate that TSFormer achieves state-of-the-art performance across multiple benchmarks: it improves over the strongest baseline by 8.05 mAP on Talk2Sensors, and transfers to the monocular Mono3DRefer benchmark with 53.05\% Acc@0.5.

## 2. 论文提出的方法论

**总体架构**：TSFormer采用端到端统一的Transformer架构，包含三个核心模块：语言路由属性采样器（LRPS）→ 稀疏保持模态仲裁器（SPMA）→ 接地解码器与预测头。

### （1）语言路由属性采样器（LRPS）—— 粗粒度文本条件特征检索
- **核心思想**：将采样过程变成查询驱动的过程，利用全局文本语义调制各传感器的采样权重，实现语言感知的初步锚定。
- **关键步骤**：
  - **文本投影**：将全局文本特征t通过模态特定投影φ_m映射到各传感器语义空间：t_m = φ_m(t)。
  - **查询级文本-传感器相似度计算**：将投影后的文本特征与对象查询Q进行通道级交互，得到相似度图D_m。
  - **调制因子生成**：通过可学习温度参数τ_m和sigmoid函数将相似度转为有界调制因子：G_m = σ(τ_m · D_m)。
  - **注意力调制**：将调制因子广播到采样注意力权重上，在Softmax前进行逐元素调制。
  - **多尺度可变形注意力**：结合调制后的注意力权重与偏移量，聚合采样位置周围的传感器特征。

### （2）稀疏保持模态仲裁器（SPMA）—— 细粒度模态仲裁与文本引导细化
- **核心思想**：在粗粒度锚定后，通过文本条件门控机制动态选择最相关的传感器线索，并防止密集模态（如相机）淹没稀疏但关键的信号（如雷达）。
- **关键步骤**：
  - **全局文本向量提取**：对文本标记特征做均值池化并投影。
  - **模态门控网络**：通过线性层、非线性激活、层归一化等结构，从全局文本向量预测每个模态的权重。
  - **Top-K稀疏选择**：可选的Top-K掩码鼓励稀疏模态路由，保留最相关的K个模态。
  - **加权融合**：将门控权重广播到所有查询标记和通道，对各模态采样特征进行加权求和：F_s = Σ α_m · O_m。
  - **文本引导交叉注意力**：以融合传感器特征为查询、文本标记为键/值，执行多头交叉注意力，实现细粒度语义对齐与细化。

### （3）接地解码器与预测头
- 采用DETR风格的集合预测范式，堆叠多层解码器逐步细化查询表示。
- 预测头输出二值指代置信度（是否为目标物体）和3D边界框参数（中心坐标、尺寸、偏航角）。偏航角使用正弦-余弦编码解决角度周期性不连续问题。

### （4）训练目标
- 使用匈牙利算法进行最优二分匹配，匹配成本综合考虑指代置信度、L1框回归损失和3D GIoU损失。
- 通过交叉熵损失监督匹配的正样本与未匹配的负样本。
- 在中间解码层施加辅助监督以加速收敛。

## 6. 论文的主要结论与发现

1. **TSFormer在Talk2Sensors上全面领先**：三传感器配置下达到EAA mAP 51.000 / DCA mAP 66.499，较最强融合基线FUTR3D提升+8.05/+7.62。在每个传感器配置下均取得最优结果。
2. **语言引导的路由带来单调性能增益**：随着传感器增加（LiDAR-only 46.18 → L+R 48.28 → C+L+R 51.00），TSFormer性能单调提升，而基线FUTR3D在三传感器融合时（42.949）反而低于其LiDAR-only水平，说明稠密相机特征淹没了稀疏雷达信号。
3. **增益集中在雷达相关提示**：TSFormer对Radar Only（+8.03）、Camera+Radar（+8.16）和C+L+R（+10.83）的提示提升最大，验证了属性路由设计动机。
4. **无文本变异几乎失效**（mAP 0.007），证明任务确实是引用性而非穷举性检测。
5. **LiDAR是几何骨干**：单模态中LiDAR表现最好（46.182 mAP），去除LiDAR时所有方法性能急剧下降。
6. **模态丢失时退化更平滑**：TSFormer在移除相机（−5.17 vs 基线−7.64）和雷达（−4.34 vs −4.56）时退化更小。
7. **跨数据集泛化能力强**：在Mono3DRefer上取得53.05% Acc@0.5（Overall），显著优于专用方法Mono3DVG-TR（44.25%），即使利用KITTI的LiDAR增强也仍保持优势。
8. **LRPS与SPMA互补**：单独添加分别贡献+4.33和+3.67 mAP，联合添加+7.78，证明两者作用互补而非重叠。

## 7. 优点

1. **开创性数据集设计**：Talk2Sensors是首个三传感器（Camera+LiDAR+4D radar）3D视觉定位数据集，填补了现有研究的关键空白。
2. **严格的物理语义对齐**：设计了量化-标注-验证的闭环标注流程，通过可视化物理量（距离同心圆、速度/深度/雷达散射截面投影）消除主观偏差，由三名专家交叉验证所有样本。
3. **创新的语言驱动融合范式**：与现有基于刚性几何投影或语言无关的融合不同，TSFormer首次利用自然语言语义动态路由传感器注意力，真正实现属性感知融合。
4. **稀疏信号保护机制**：SPMA的软门控+Top-K稀疏路由有效解决了稠密模态（相机）淹没稀疏模态（雷达）的关键问题。
5. **传感器配置灵活**：LRPS的查询驱动采样设计不依赖刚性的标定投影，可推广到任意传感器子集。
6. **实验体系完整且公平**：所有基线统一重新实现，消融实验覆盖全面，同时报告精度和效率的权衡。
7. **文本仅作为语义引导、不预测类别**：遵循视觉定位范式（而非类别级检测），更符合真实场景中开放式语言查询的需求。

## 8. 不足与局限

1. **数据来源单一**：Talk2Sensors仅基于View-of-Delft（VoD）数据集，来自荷兰代尔夫特单一城市环境。与KITTI、nuScenes等覆盖多城市、多云雨条件的大规模数据集相比，场景多样性有限，可能限制模型的泛化能力。
2. **数据规模有限**：8,682条指令和20,558个对象在当今VLM时代规模相对较小，可能不足以支持大规模预训练。
3. **提示长度限制**：使用CLIP ViT-B/32作为文本编码器，最大支持77个token。Talk2Sensors提示平均20.2词，部分长提示可能接近截断限制。
4. **传感器配置要求高**：TSFormer的完整性能需要三传感器同时可用，在硬件降级或传感器部分失效的实际场景中，虽然展示了一定的模态丢失鲁棒性，但退化仍然明显（去除LiDAR时性能显著下降）。
5. **推断速度有提升空间**：三传感器配置下9.2 FPS仅接近实时，在要求极低延迟的自动驾驶场景中可能尚不足以满足严格部署需求。
6. **未覆盖恶劣天气**：论文在结论中承认，未来的研究方向之一是扩展到恶劣天气和夜间场景，而4D雷达在这些条件下的互补鲁棒性优势正是关键卖点之一，但当前实验未予以验证。
7. **未包含时间推理**：目前是静态帧级定位，未利用时序信息来增强连续运动学接地，限制了处理动态场景中复杂运动语义的能力。
8. **文本提示的“物理性”约束本身可能限制表达的自然性**：严格禁止主观推断和情感描述虽然保证了与传感器测量对齐，但可能偏离真实用户交互中语言的自然分布。
