## 摘要
世界动作模型（WAMs）通过预测观察到的世界将如何演变来学习与动作相关的表征。大多数现有的WAMs在RGB空间中定义这种未来，其中与任务相关的状态转换与纹理、光照、背景和视角中的干扰变化纠缠在一起。我们认为WAMs应该显式地预测与动作相关的未来状态，而不是仅依赖RGB预测。我们引入了DreamWAM，它将未来预测重新表述为超越RGB的结构化世界建模，通过外观、运动、几何和语义的互补视图来表示未来状态。在训练期间，DreamWAM将RGB和运动的联合潜在去噪与用于几何和语义的轻量级门控残差分支相结合。VideoDiT和ActionDiT之间的共享注意力使得动作分支能够从这些未来状态预测中学习，而在推理时所有超越RGB的监督分支都被禁用，部署保持仅RGB。在无滚动和联合视频-动作推理两种情况下，DreamWAM在LIBERO上一致地优于匹配的仅RGB基线，分别从97.30%提高到98.40%和从98.00%提高到98.90%。在未见过的LIBERO-Plus扰动下，增益变得更大，从51.36%提高到63.44%和从69.16%提高到75.47%。同样的鲁棒性也扩展到真实世界操作，DreamWAM在光照、背景和物体布局的未见变化中达到了74.4%的平均成功率，而Fast-WAM-Joint为55.6%。这些结果表明，稳健的世界动作学习不仅依赖于预测未来，还依赖于以对动作重要的形式来表示它。代码和模型公开发布在https://github.com/hustvl/DreamWAM。

## Abstract
World Action Models (WAMs) learn action-relevant representations by predicting how the observed world will evolve. Most existing WAMs define this future in RGB space, where task-relevant state transitions are entangled with nuisance variations in texture, illumination, background, and viewpoint. We argue that WAMs should explicitly predict action-relevant future state rather than relying on RGB prediction alone. We introduce DreamWAM, which reformulates future prediction as structured world modeling beyond RGB, representing future states through complementary views of appearance, motion, geometry, and semantics. During training, DreamWAM combines joint latent denoising of RGB and motion with lightweight gated residual branches for geometry and semantics. Shared attention between VideoDiT and ActionDiT allows the action branch to learn from these future-state predictions, while all beyond-RGB supervision branches are disabled at inference and deployment remains RGB-only. Across both no-rollout and joint video-action inference, DreamWAM consistently improves the matched RGB-only baselines on LIBERO, from 97.30\% to 98.40\% and from 98.00\% to 98.90\%, respectively. The gains become larger under unseen LIBERO-Plus perturbations, from 51.36\% to 63.44\% and from 69.16\% to 75.47\%. The same robustness extends to real-world manipulation, where DreamWAM attains an average success rate of 74.4\% across unseen changes in lighting, background, and object layout, compared with 55.6\% for Fast-WAM-Joint. These results show that robust world-action learning depends not only on predicting the future, but on representing it in a form that matters for action. The code and models are publicly released at https://github.com/hustvl/DreamWAM.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：世界动作模型（World Action Models, WAMs）通过预测世界的未来演化来学习与动作相关的表征，但现有 WAMs 几乎都在 RGB 图像空间中定义“未来”。RGB 预测将任务相关的状态转换（如物体位移、接触、目标完成）与任务无关的视觉变化（纹理、光照、背景、视角）纠缠在一起，导致模型在视觉分布偏移下泛化能力不足。
- **关键洞察**：有效的“未来想象”不应是像素级还原下一帧画面，而应保留与动作成功相关的状态信息——即“什么物体参与、如何变化、在哪里变化”。即使像素外观发生巨大变化，操作目标可以保持不变；反之，仅靠 RGB 外观拟合可能忽略决定动作成败的状态演化。
- **研究意义**：论文提出“预测未来时应该表征什么”是 WAMs 设计中的核心变量，而不只是“如何预测未来”。鲁棒的世界动作学习不仅需要预测未来，更需要以对动作有意义的形式来表示未来。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 2.1 核心思想

DreamWAM 将未来预测重构为**超越 RGB 的结构化世界建模**，用四种互补视图描述未来状态：

- **外观（Appearance）**：未来 RGB 序列，由视频 VAE 编码为标准外观潜在表示。
- **运动（Motion）**：用 RAFT 估计相邻未来帧间的稠密光流，经同一 VAE 编码为运动潜在表示，显式刻画时间变化。
- **几何（Geometry）**：用 Depth Anything V3 提取深度结构特征，捕获空间组织与相对位置关系。
- **语义（Semantics）**：用 DINOv2 提取 patch 级特征，保持物体与区域级的一致性。

这些视图是动作相关未来状态的关联投影，而非完全解耦或完整的物理描述。

### 2.2 技术实现：两条异构建模路径

**（1）RGB 与运动的联合潜在去噪（Joint Latent Denoising）**

- RGB 和光流共享相同的稠密时空结构，因此在训练时在同一 flow-matching 时间步加噪，并沿通道维度拼接：

```
x_t^q = (1−t)·z_q + t·ε_q,  q ∈ {rgb, mot}
x_t^joint = Concat_C([x_t^rgb, x_t^mot])
```

- VideoDiT 在同一个去噪流中同时学习两个视图，使运动成为显式的未来预测目标，而非隐含在 RGB 中。

**（2）几何与语义的门控残差建模（Gated Residual Modeling）**

- 深度和语义特征来自外部编码器，与 VAE 潜在空间不同源；若直接作为额外去噪通道拼接，会干扰预训练视频生成先验。
- 因此采用轻量级门控残差分支，在选定的 VideoDiT 层进行受控修正：

```
h̄_ℓ = B_ℓ(h_{ℓ−1})
h_ℓ = h̄_ℓ + Σ_j g_j^ℓ(h̄_ℓ, c) ⊙ R_j^ℓ(h̄_ℓ)
ĥ_j = P_j(h_L)
```

- 残差分支保留了原始块输出作为主通路，门控信号控制每个视图修正的幅度，从而“细化而非替代”预训练视频表示。

### 2.3 世界-动作耦合

- 采用双专家 VideoDiT–ActionDiT 架构：VideoDiT 建模未来状态表示，ActionDiT 去噪动作轨迹。
- 配对层通过共享注意力交换信息，使 ActionDiT 能在训练期间条件于多视图未来表示，而无需直接消费光流、深度或语义教师特征。
- 这是关键设计：额外的未来视图不是孤立的辅助任务，而是通过重塑 VideoDiT 表示直接影响动作学习。

### 2.4 训练目标与推理

- 总损失：各任务损失的加权和，外加门控激活的 ℓ1 正则化。

```
L = λ_rgb·L_FM^rgb + λ_mot·L_FM^mot + λ_geo·L_pred^geo + λ_sem·L_pred^sem + λ_act·L_FM^act + λ_g·L_gate
```

- **训练时**：运动路径、门控残差分支、特征预测头均激活；所有非 RGB 目标从训练视频离线预计算。
- **推理时**：运动输入用零填充（由于输入投影的线性性质，零通道不产生贡献），所有残差分支、预测头、RAFT、Depth Anything V3、DINOv2 全部移除，只保留 RGB 视频-动作去噪路径，部署接口与 Fast-WAM 完全一致。

## 3. 实验设计：数据集、场景与对比方法

### 3.1 仿真实验

- **LIBERO**：包含 Spatial、Object、Goal、Long 四个 10 任务套件，每任务 500 条演示。仅在原始 LIBERO 演示上训练，每任务评估 50 次 rollout（每种子 2000 次）。
- **LIBERO-Plus**：在保持任务语义与成功标准不变的前提下，引入 7 种未见过的分布偏移：相机视角、机器人外观、语言、光照、背景、图像噪声、物体布局。不使用任何 LIBERO-Plus 数据训练。每种子评估 10,030 个回合，取 7 个维度得分的未加权平均。
- **两种推理模式**：
  - 无 rollout（no-rollout）：仅用第一帧视频输入直接去噪动作。
  - 联合（joint）：同时去噪未来 RGB 潜在表示和动作。

## 6. 论文的主要结论与发现

1. **结构化未来监督可提升标准任务性能**：LIBERO 上无 rollout 模式从 97.30% 提升到 98.40%，联合模式从 98.00% 提升到 98.90%，均达到所比较方法中的最高平均水平。
2. **分布偏移下的增益显著放大**：LIBERO-Plus 无 rollout 从 51.36% 提升到 63.44%（+12.08），联合模式从 69.16% 提升到 75.47%（+6.31），且 7 个扰动维度全部提升。
3. **训练时结构化未来与测试时想象互补**：无 rollout 到联合模式的差距从 17.80 个百分点缩小到 12.02，说明部分原本需要在线提供的动作相关未来结构已被政策内化，但测试时想象仍带来额外收益。
4. **真实机器人鲁棒性提升明显**：标准任务平均成功率从 90.8% 提升到 96.7%；在未见过的光照、背景、布局变化下从 55.6% 提升到 74.4%，提升幅度大于分布内增益，与仿真中 LIBERO-Plus 趋势一致。
5. **消融揭示了视图互补性与路由匹配的重要性**：
   - 三个辅助视图在优选路由下都能提升 RGB-only 基线，其中运动是最关键信号（移除后下降最大），运动为几何和语义提供了时间“脚手架”。
   - 运动适合全去噪注入，几何和语义适合门控残差注入；三种目标全部走全去噪（D/D/D）会低于 RGB-only 基线，而混合路由（D/R/R）达到最高分。
   - 结论：辅助监督不是越多越好，**“信息内容”和“注入路径”必须匹配目标表示与预训练潜在空间的兼容性**。

## 7. 优点

- **问题提法新颖**：将“未来预测的表征形式”作为 WAMs 的核心设计维度，超越了单纯改进视频生成质量和动作耦合的常规思路。
- **方法设计实用且优雅**：通过“训练时多视图监督 + 推理时仅 RGB”的分离，既获得了丰富结构化未来监督，又不增加部署时计算负担，部署接口与 Fast-WAM 完全一致。
- **异构信息采用异构建模**：VAE 对齐的运动走联合去噪，非 VAE 源的几何/语义走门控残差，并给出消融证据表明这种路由匹配是性能提升的关键而非简单叠加监督。
- **实验设计具有高可比性**：与 Fast-WAM/Fast-WAM-Joint 的匹配对比、两条推理路径（无 rollout 与联合）、两种分布（标准与偏移）、两个环境（仿真与真实）形成完整证据链。
- **真实机器人验证**：不仅局限于仿真，还在真实双机械臂平台上验证了鲁棒性结论，并公开代码与模型，利于复现和后续研究。

- **实验覆盖相对有限**：仅在 LIBERO 语义任务系列（4 个套件、10 类任务）上训练；未在更广泛、更多样化的真实操作数据集（如 Bridge、Open-X-Embodiment 等）上验证。

- **外部教师的质量依赖**：光流（RAFT）、深度（DA3）、语义（DINOv2）均为冻结预训练模型，其误差或视觉偏差可能被间接引入政策；论文未分析教师模型质量对结果的影响。

- **推理时零填充处理的局限**：运动通道在推理时置零，虽然线性投影保证无直接输入贡献，但训练与推理的分布仍存在细微不一致（训练时条件帧的 flow 通道也为零，但未来帧的 flow 通道有噪声目标），可能影响生成行为。
- **消融只报告平均成功率和种子均值**，缺少方差、失败模式分析以及不同种子间差异的详细报告。
- **公平性问题**：与其他先进方法的比较中，骨干网络和预训练差异较大，论文也承认其主要受控证据限于 Fast-WAM 配对比较；π0、Motus 等方法结果仅供参考。
- **实际应用限制**：仍依赖由外部预训练模型离线生成的训练目标，整体训练流程复杂；对于没有现成光流/深度/语义教师的新场景，需要额外适配。
