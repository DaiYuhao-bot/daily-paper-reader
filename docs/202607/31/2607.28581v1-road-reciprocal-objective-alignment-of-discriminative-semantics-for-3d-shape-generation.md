## 摘要
高保真三维生成主要依赖于扩大模型容量和数据规模，这导致了高昂的计算成本。这种范式通常需要从头学习几何，却忽略了判别性三维基础模型中已蕴含的丰富语义和结构先验。我们认为，利用这些判别模型对三维世界的深刻理解，可以显著降低生成成本。为此，我们提出ROAD框架，通过将这些丰富的判别先验迁移到扩散变换器中，来降低三维生成的训练成本。为解决生成式与判别式潜在表示之间固有的语义-结构异质性，我们引入了一种互惠目标对齐策略。该方法协同使用整体语义凝缩以强制全局语义一致性，以及结构化最优对齐（该对齐被形式化为一个二分匹配问题，用以严格对齐不同潜在空间中的微观几何细节）。该三维基础模型仅用于训练时的对齐监督，推理时不使用，因此不会增加额外推理成本。与工业基线Step1X-3D相比，所提出的ROAD仅使用1.5%的训练数据即可实现极具竞争力的生成性能，并显著降低训练成本，有效减少了高保真三维生成的计算开销。代码可在 https://github.com/H-EmbodVis/ROAD 获取。

## Abstract
High-fidelity 3D generation predominantly relies on scaling model capacity and data, which incurs prohibitive computational costs. This paradigm typically requires learning geometry from scratch and overlooks the rich semantic and structural priors already encapsulated in discriminative 3D foundation models. We contend that leveraging the profound understanding of the 3D world possessed by these discriminative models can significantly reduce generative cost. To this end, we propose ROAD, a framework that reduces the training cost of 3D generation by transferring these rich discriminative priors into diffusion transformers. To address the inherent semantic-structural heterogeneity between generative and discriminative latents, we introduce a reciprocal-objective alignment strategy. This method synergizes Holistic Semantic Condensing to enforce global semantic coherence and Structural Optimal Alignment, which is formulated as a bipartite matching problem to rigorously align microscopic geometric details between disparate latent spaces. The 3D foundation model is only used for training-time supervision of alignment and is not used at inference, incurring no additional inference cost. Compared with the industrial baseline Step1X-3D, the proposed ROAD achieves highly competitive generation performance with only 1.5% of the training data and significantly reduces training costs, effectively reducing the computational overhead of high-fidelity 3D generation. Code is available at https://github.com/H-EmbodVis/ROAD.

- **核心问题**：能否利用判别式 3D 基础模型（如 Uni3D）中预训练好的通用三维表征，作为生成模型的"认知捷径"，从而以极少的训练数据和算力实现高保真三维生成？

- **核心难点**：生成模型（3SDM）与判别模型（3DFM）的潜在表示之间存在**语义-结构异质性**（semantic-structural heterogeneity），这是先验迁移的主要障碍。具体表现为：（1）3D 点云具有置换不变性，导致 token 序列缺乏确定性对齐；（2）两者的编码架构不同——VAE 通过交叉注意力将全局上下文聚合到稀疏锚点上，token 是全局且位置无关的；而 3DFM 通常通过 KNN 等分组操作编码局部几何特征，token 保持局部区域分布。这使得 2D 生成中成熟的"逐元素空间对齐"策略在 3D 领域失效。

- **整体含义**：论文主张用语义对齐替代庞大的数据规模，为 3D 生成社区提供一条降低资源门槛的可行路径。

## 2. 论文提出的方法论

### 核心思想
提出 **ROAD（Reciprocal-Objective Alignment of Discriminative Semantics）** 框架，通过在训练阶段将**冻结的 3D 基础模型**（采用 Uni3D-G）作为语义监督器，注入到 3D 扩散 Transformer（3SDM）中，实现跨潜在空间的**多粒度协同对齐**。该 3DFM 仅在训练时使用，推理时无任何额外开销。

### 关键技术与公式

**（1）特征投影与归一化**
- 从 3SDM 的中间层提取特征 X，经由轻量级 MLP 投影器 Φ_MLP 映射到 3DFM 的潜在空间，得到 Z = Φ_MLP(X) ∈ R^{N×D'}；3DFM 提取的特征记为 Y ∈ R^{M×D'}。
- 对二者进行 L2 归一化（得到 ẑᵢ 和 ŷⱼ），以增强对齐稳定性。

**（2）整体语义凝缩（Holistic Semantic Condensing, HSC）**
- 针对 token 无序性问题，通过全局平均池化将两组 tokens 分别聚合成语义原型（centroid）：
  - c_z = (1/N) Σ ẑᵢ，c_y = (1/M) Σ ŷⱼ
- HSC 损失定义为两者之间的余弦距离：L_HSC = 1 − cos(c_z, c_y)
- 作用：确保生成模型在宏观语义流形上与基础模型保持一致，回答"生成什么"的问题。

**（3）结构化最优对齐（Structural Optimal Alignment, SOA）**
- 为保留 HSC 聚合过程中丢失的微观几何细节，将局部映射建模为**二分匹配问题**：
  - 先通过自适应平均池化将 Z 下采样至 M 个 token（与 3DFM token 数量等基），得到 Z′ ∈ R^{M×D'}，同时起到抑制训练噪声的作用。
  - 构建基于余弦距离的代价矩阵 C ∈ R^{M×M}：C_{i,j} = 1 − cos(z′ᵢ, yⱼ)
  - 使用**匈牙利算法**（Hungarian Algorithm）寻求最优置换 π*，最小化总匹配代价：
    - π* = argmin_π Σᵢ C_{i,π(i)}
  - SOA 损失为匹配后对应 token 的平均余弦距离：L_SOA = (1/M) Σᵢ C_{i,π*(i)}
- 作用：通过语义相似性而非空间坐标建立 token 对应关系，实现细粒度几何约束，回答"如何生成细节"的问题。

**（4）训练目标**
- 总损失 = 标准扩散损失 + 双对齐约束：L = L_diff + λ₁L_HSC + λ₂L_SOA，其中 λ₁ = λ₂ = 0.5。

**（5）语义层选择分析**
- 论文在 ModelNet40 上训练线性分类器探查不同 DiT 层的语义判别力，发现**第 6 层（Double-Stream Block）** 准确率最高（91.7%），表明该层语义最强，故选择该层进行特征对齐。后续实验中 Layer 6 的消融结果也验证了这一选择的合理性。

### 框架流程（文字描述）
输入 3D 形状 → VAE 编码为潜在 tokens → 加噪后送入 DiT（含双流/单流模块）→ 在指定 DiT 层提取中间特征 → MLP 投影 + L2 归一化 → 分别通过 HSC（全局池化+余弦损失）和 SOA（匈牙利匹配+余弦损失）与冻结的 3DFM 特征进行对齐约束 → 与扩散损失联合优化更新 DiT 参数。

## 6. 论文的主要结论与发现

1. **判别先验可替代数据暴增**：ROAD 仅用工业基线 1.5% 的数据（30k vs. 2000k）和约 1/3 的 GPU 算力，即达到与 Step1X-3D 相当甚至更优的性能（Uni3D-Score 32.3 vs. 33.5，ULIP-Score 33.7 vs. 34.4），并在某些指标上超越 TRELLIS、Direct3D-S2 等强基线，验证了语义对齐作为暴力扩展替代方案的可行性。

2. **语义-结构异质性是 3D 表示对齐的关键障碍**：直接的逐元素对齐在 3D 生成中不仅失效甚至有害（性能下降），需要针对无序点云和异构编码架构设计专用对齐策略。

3. **HSC 和 SOA 具有协同效应**：二者单独使用效果有限（ULIP 32.8/33.2），组合后显著提升至 33.7，说明全局语义和局部结构的互补性是完整迁移判别先验的必要条件。

4. **语义相似性而非空间坐标是正确匹配依据**：基于点坐标的空间匹配（ULIP 32.4）会破坏生成模型的潜在拓扑，而基于特征余弦的匹配（33.7）最优。

5. **更强的基础模型提供更优先验**：1B 参数 3DFM 对齐效果优于 0.3B 版本；3D 原生基础模型优于 2D（DINOv2）和 2.5D（VGGT）模态的对齐效果。

6. **显著加速收敛**：ROAD 达到基线峰值性能的时间约 55k 次迭代，为基线（130k+）的 2.4 倍加速。

7. **跨架构可迁移**：在 CraftsMan 和 TRELLIS 架构上的一致提升表明该方法具有架构通用性。

## 7. 优点

- **问题洞察深刻**：论文清晰地揭示了 3D 生成与判别模型之间的语义-结构异质性（全局 vs. 局部 token 编码、置换不变性），通过可视化（特征投影）和实证（空间匹配失败）双重验证，分析扎实。

## 8. 不足与局限

- **数据来源单一**：训练和测试均来自 Objaverse，仅限于物体级 3D 资产，未覆盖室内场景、大规模城市场景等复杂领域，限制了结论的泛化范围。
- **测试规模有限**：仅 160 个测试对象，统计显著性可能不足；CLIP-based 评估指标无法全面反映几何真实感（如拓扑正确性、物理合理性、表面质量等）和用户偏好，缺乏人工评估或更全面的几何指标（如 FID、覆盖率、MMD）。
- **实验基准和数据规模不足**：与商业模型（Step1X-3D、Hunyuan3D）比较时，采用剪枝后的 0.65B 参数模型，且仅使用少量公开数据，虽然展现了效率优势，但无法验证在同等规模数据下能否达到完全一致的生成多样性；对比基线中 Direct3D-S2 和 TRELLIS 的数据是私有或 500k，与 30k 的数据量差异也可能引入不公平性因素。
- **依赖基础模型能力**：生成质量的"天花板"受限于 3DFM 的语义容量表达上限，若基础模型对某些类别或风格的理解不足，生成效果将受到直接制约。文中虽提及此局限，但未展开讨论具体失效场景。
- **对齐层选择的经验性**：最佳对齐层（第 6 层）通过 ModelNet40 分类任务确定，该策略与最终生成质量之间的相关性未被充分论证；最佳密度（10k）和超参数（λ₁=λ₂=0.5）也缺乏敏感性分析。
- **仅限图像条件生成**：实验主要集中在单图到 3D 的生成设置，未验证文本条件、类别条件等其他条件输入下的有效性。
- **缺少与全尺寸基线的对照**：论文中的"基线"是剪枝后的 Step1X-3D*（6 双流 + 12 单流），未与原版 Step1X-3D（12+24）在相同数据下训练对比，因此 ROAD 在小型模型上的收益是否能推广到大型模型仍需进一步证实。
